# MJYT support

Use the repository's Issues area for reproducible bugs, compatibility problems, and feature requests relating to the published MJYT binary.

## Before opening an issue

1. Confirm you are using the latest published MJYT release.
2. Reproduce the issue once with the same media/workflow.
3. Check whether the problem is already reported.
4. Avoid posting private, members-only, account-authenticated, rented/purchased, or otherwise sensitive media URLs.

## Include with a bug report

- MJYT version, for example `v1`.
- Windows version.
- Whether the URL is a video, playlist, or supported live-stream case.
- The selected format/audio/subtitle settings if relevant.
- Clear reproduction steps.
- The exact user-visible error or status text.
- A screenshot or sanitized log excerpt when useful.

If a full URL is not necessary to reproduce the issue, redact the video or playlist identifier before posting publicly.

## Unsupported requests in v1

The following are not supported product workflows in MJYT v1:

- Account login/cookie import.
- Private videos.
- Members-only videos.
- Rented or purchased media.
- DRM circumvention.
- General non-YouTube site downloading.

## Source-code support

This is a binary/documentation repository. MJYT application source code is not published here, and source-level build/support requests are not handled through this public repository.
