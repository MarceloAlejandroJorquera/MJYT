# MJYT v1.1

MJYT v1.1 updates native streaming and publicly accessible YouTube playlist extraction.

## Changes since v1

- Fixed completed livestream and supported live-stream downloads, retaining native DASH/HLS support.
- Improved enumeration of public standard playlists, generated radio Mixes, and public YouTube Music compilation playlists (`RDCLAK...`).
- Supported modern playlist renderer/continuation response structures and improved diagnostics for unrecognized playlist inventory.
- Preserved native video/audio selection, subtitles, metadata, queue/history, bandwidth policy, and portable single-EXE runtime.

## Download

Download `MJYT-v1.1-windows-x64.zip`, extract it and run `MJYTv1.1.exe`. The ZIP includes the executable and `SHA256SUMS.txt` for the executable. The separately attached `SHA256SUMS.txt` verifies the release ZIP and executable.

## Requirements and limitations

Windows 10/11 x64. MJYT supports only public, otherwise-accessible media. Private, members-only, account-authenticated, paid, rented/purchased, and DRM-protected content is not supported. MJYT does not bypass authentication or digital rights management. Availability depends on YouTube's public response behavior.
