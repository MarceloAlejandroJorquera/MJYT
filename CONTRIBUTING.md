# Contributing

This repository is the public documentation and release-information home for MJYT. The MJYT application source code is not published here.

## Useful contributions

Public contributions can focus on:

- Clear, reproducible bug reports.
- Documentation corrections.
- Compatibility reports for supported Windows versions and public YouTube media workflows.
- Feature requests that describe the user problem and expected behavior.

## Not accepted through this repository

- Reconstructed or reverse-engineered application source.
- Patches that require unpublished MJYT source files.
- Requests to add account-authentication, private-video, members-only, rented/purchased, or DRM-bypass functionality.
- Third-party binaries or bundled executables submitted without an explicit maintainer request.

Before submitting a pull request for documentation, keep changes limited to files already intended for public distribution and avoid adding private paths, credentials, internal build artifacts, or unpublished source material.
