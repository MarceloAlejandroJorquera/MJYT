# Release assets

MJYT binaries are published through GitHub Releases rather than committed to the normal repository tree.

For `v1`, the intended public binary assets are:

```text
MJYTv1.exe
MJYT-v1-windows-x64.zip
SHA256SUMS.txt
```

The project does not publish an MJYT application-source ZIP as a release asset.

GitHub may additionally display automatically generated **Source code (zip)** and **Source code (tar.gz)** links. Those files are snapshots of this documentation repository at the release tag and are not the MJYT application source code.
