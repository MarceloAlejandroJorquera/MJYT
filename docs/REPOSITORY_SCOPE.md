# Public repository scope

This repository is the public documentation and release-information repository for MJYT.

## Included

The repository is intended to contain only material suitable for public distribution, such as:

- README and release notes.
- Changelog.
- Usage/support/security documentation.
- Screenshots.
- Versioning and release-integrity documentation.
- Third-party license notices required for public binary distribution.

## Not included

The repository does not publish:

- MJYT application source code.
- Internal build scripts or compiler configuration.
- Internal qualification/verifier tooling.
- Development patches or rollback material.
- Private repository history.
- Debug symbols or intermediate build products.

## GitHub-generated source archives

GitHub may show automatically generated **Source code (zip)** and **Source code (tar.gz)** links for tags/releases. Those archives are snapshots of this public documentation repository. They do not contain the unpublished MJYT application source code.

## Binary releases

Compiled MJYT binaries are published separately as GitHub Release assets rather than committed into this repository's normal Git tree.
